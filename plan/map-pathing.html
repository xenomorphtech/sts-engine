Correction to the working assumption: the baked elite_afford_hp is 0.574 (0.674 at A20 via the +asc/200 term); the real elite-avoidance mechanism is the strength gate (~12.5 in Act 1, ~17 in Act 2 with slope 4.59) plus penalty −56 vs value +18. That's what produces 1.3 elites/run.

Why "avoid elites, smith everything" breaks at A20

  1. Hallway fights stop being free (A2/A7/A17). The elite decision is a ratio: (elite HP cost − normal HP cost) vs a permanent, compounding relic. At A20 the marginal HP price shrinks while the payoff is unchanged.
  2. All non-elite income is taxed (A12 fewer upgrades, A13 −25% boss gold, A16 +10% shops, A14 −maxHP, A10 Bane eats a removal). Smithing is the one untaxed channel — which is why the A0 ES leaned on it — but A20's damage checks aren't upgrade checks:
  3. The A20 double boss is a scaling check. Two boss fights, one HP pool, no campfire between. A "barely beats one boss" smith-only deck loses fight two; relic scaling is what turns fight one from 65% HP cost into 30%.
  4. A final-act win requires one elite anyway (emerald key on the burning elite) — zero-elites isn't a legal winning strategy once Act 4 exists.

Conditional consensus: "2–3 elites by mid-Act-2" holds when relics are your scaling plan. Defect frost is the exception — its scaling is card-driven — but the skip is only right when the engine is already online, the elite is a bad matchup (A18 Nob +3 Str per skill = frost Defect's worst enemy), or HP/potions can't cover. When the engine hasn't materialized by floor ~10, elites are more necessary. And a strong frost engine cuts both ways: elites become cheap. The optimum is "fight because it's cheap," not "skip because it's unnecessary" — except vs Nob.

engine_power = w_frost·frost + w_focus·focus + w_upg·upgrades + w_aoe·aoe + w_big·big_attacks

A 90%-HP weak deck is correctly denied; a 55%-HP frost machine is correctly allowed. The elite_decay counter is what lets the optimizer find "2–3, then stop" instead of all-or-nothing.

Path planning redesign: forward DP over survivor state

Defect of the current recursion: node_value is a full max-path DP but with frozen state — HP/gold/strength evaluated at today's values for every future node. It cannot represent "monster → rest → elite" as a plan; rest_preboss_value and the y≥14 hack are patches over the missing "state at arrival" concept.

Proposal: forward DP over (node, hp-bucket ×10, gold-bucket ×6, key-bits ×8):

for each row y, node n, state s with value v:
    (dv, s2) = apply_room(n.room, s)      // reward + state transition using fl_* params,
    relax children with (v + dv, s2)      // gold EVs, upgrade EVs
terminal at boss row: boss_hp_weight·hp(s) + key bonuses [+ act3: second-boss reserve]
return first edge of argmax path
  • Rest is a decision node inside the DP — max(rest: +30% HP, smith: upgrade EV, recall: key bit). "Smith now because a rest sits before the boss" becomes emergent.
  • ~50k states × 3 edges ≈ 150k trivial relaxations → <1 ms, ≤16 calls/act. Opposite regime from the failed 2-turn combat lookahead (cheap closed-form EVs vs noisy 5× rollouts); replans every floor so model error self-corrects.
  • Migration: land with room-EVs initialized to reproduce current orderings (default-preserving), validate neutrality, then open the dims to the ES. Never ship DP + retuned params as one bundle.

Rest / shop / key policies

  • Rest: correct threshold is path-conditional: rest iff hp < planned_loss_to_next_rest + reserve — the DP computes it natively. Until then: rest_hp_preboss3 ≈ 0.9 for the double boss; first Act-2 campfire rests only if an elite is planned within rest_lookahead_floors; both global threshold shifts already failed at A0 — conditioning on the path is the whole point.
  • Shops (A16): removal ≈ 82+ rising, so raise routing gate shop_route_gold_min 120→140; add need-conditional routing bonus (no AoE by Act 2, zero focus sources, Bane still in deck, empty potion slots). Purchase logic is deck-aware; routing is deck-blind today — the bot buys well but arrives poor.
  • Keys: ✅ key-chasing is gated while Act 4 is unreachable. Once Act 4 entry is fixed: emerald preferably in Act 2 (an elite you wanted anyway); ruby = spend the lowest-value campfire; sapphire at the least-valued treasure.
  • Act 4: fixed 3-node map; rest unless hp ≥ act4_rest_hp (0.85); Act-3 terminal reserves HP when keys complete.

Ranking

  1. Deck-power-conditional elite affordance + relic payoff with decay — attacks the measured discriminator (wins 2.0 vs losses 0.5 elites), lets ES find the equilibrium.
  2. State-evolving path DP — unlocks rest-before-elite / arrive-rich / key routing as emergent plans; near-zero runtime.
  3. Path-conditional rest thresholds (pre-double-boss reserve, elite-ahead boost) — boss-entry HP was the other measured discriminator (63% vs 45%).
  4. Matchup extensions (asymmetric payoff: prevents catastrophic fights).
  5. Shop routing; key/Act-4 refinements (mostly free under the DP).
