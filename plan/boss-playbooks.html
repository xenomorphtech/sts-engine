Engine ground truth (changes the ranking)

  • GAP Four fights don't exist: no MonsterId for Time Eater, Nemesis, Reptomancer, Spire Growth. The generator schedules them by name, then game.rs:2946-2950 falls back: unknown boss → Hexaghost, unknown elite → Gremlin Nob, unknown normal → Cultist. "Time Eater losses" are Act-3 Hexaghost-proxy losses; Giant Head is the only real Act-3 elite (why it dominates Act-3 elite deaths).
  • GAP Corrupt Heart is simplified: 750 HP, Artifact 2, Debilitate, then fixed cycle Echo 40 → Buff +2 Str → Blood Shots 12×(2+Str). No Beat of Death, no Invincible cap, no buff ladder — in-engine the Heart is a pure uncapped race.
  • Spire Shield/Spear are simplified (no back-attack, no Artifact) — near-free with existing priorities.
  • The beam search already prices anything resolving this turn (Sharp Hide chip, Mode Shift flips, Nob skill→Str). The systematic blind spots: (a) scripted spikes ≥2 turns out, (b) status-card pollution (invisible to score_state), (c) static target priorities, (d) overblock_penalty punishing frost banking the turn before a scripted spike.

The one mechanism that covers six loss buckets

Scripted-spike table DET: fn scripted_incoming(monster, player, turns_ahead) → i32 next to projected_incoming, reading each boss's deterministic script (next_move / extra counters):

  • Hexaghost: T2 Divider = 6×(hp/12+1); Inferno timing from extra
  • Bronze Automaton: HYPER BEAM next turn iff extra==4; stun turn after beam → suppress blocking value
  • Corrupt Heart: cycle from extra%3 — Echo 40+2k / Blood Shots 12×(2+2k)
  • Giant Head: It's Time = 30+5k capped 60 once extra≤2
  • The Collector: Mega Debuff turn (extra==2) → pre-bank frost
  • Awakened One: Dark Echo 40 on rebirth

In score_state: value −= (scripted_next − frost_bank − block).max(0) × spike_danger, and suppress overblock_penalty whenever scripted_next > incoming. ES spike_danger (10, 0–40), spike_horizon (2, 1–3).
